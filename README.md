# Журнал зала

Личное веб-приложение для записи тренировок: работает на телефоне без интернета, данные хранятся только на устройстве.

- Шаблоны тренировок, подсказка «прошлый раз», таймер отдыха, график прогресса, резервная копия.
- База упражнений с фото, описанием, подбором аналогов под оборудование зала и ссылками на видео.

## Источники

- Список упражнений и фотографии: [free-exercise-db](https://github.com/yuhonas/free-exercise-db), лицензия Unlicense (общественное достояние). Русские названия и подсказки по технике добавлены вручную.
- Пошаговые описания на русском составлены вручную по материалам базы.
- Видео: ссылки на YouTube, в основном на русском. Проверялась доступность и соответствие названию; квалификация авторов и техника в видео не проверялись.

Приложение носит справочный характер и не заменяет тренера или врача.
